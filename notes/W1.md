# W1 · 系统与网络地基（环境搭建）

## 环境
- VMware + Ubuntu Server 24.04.4 LTS，主机名 jinertext，用户 jiner
- 网段 192.168.142.0/24（NAT，DHCP）→ W3 改静态
- 工作方式：宿主机 SSH 进 VM，不用 VMware 控制台窗口

## 已跑通的服务
- opslab.service：Python HTTP 服务，监听 0.0.0.0:8000，以 opslab 系统用户运行（无登录权限）
- nginx：默认站点，宿主机可访问 http://192.168.142.143

## 踩过的坑
1. status=0/SUCCESS 且 Duration 只有几十毫秒 —— 不是配置错，是脚本跑完就退出了。
   排查第一步：把 ExecStart 的命令手工跑一遍。
2. 从渲染过的代码块复制会带进零宽空格 U+200B，导致 if 条件恒为 False、
   脚本静默正常退出。检查命令：
   python3 -c "print(open('文件名',encoding='utf-8').read().count(chr(0x200b)))"
3. 改完 unit 文件必须 systemctl daemon-reload，否则修改不生效。
4. Restart=on-failure 对 SIGTERM 不生效（systemd 视为干净退出），验证要用 kill -9。
5. 不要 sudo su：root 的 ~ 是 /root，git config 和新建文件属主都会错。
6. kill 之前先判 MainPID 是否为 0，否则 kill -9 0 会杀掉整个进程组。

## 验证过的能力
- 写 systemd unit：Unit / Service / Install 三段，Type、User、ExecStart、Restart、WantedBy
- systemctl：daemon-reload、enable --now、status、show -p NRestarts
- journalctl -u <服务> -f 看实时日志
